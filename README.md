# Python Fuzz Testing with Atheris

## Overview
This project implements fuzz testing using [Atheris](https://github.com/google/atheris), a Python fuzzing engine.  
It is designed for security and reliability testing of Python functions, particularly in **software engineering research**.

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/biplab4/python-fuzz-tester.git
cd python-fuzz-tester
python3 -m venv fuzz_env
source fuzz_env/bin/activate
pip install -r requirements.txt
